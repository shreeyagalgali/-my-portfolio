# Shreeya Galagali – UX Portfolio

A static portfolio site (plain HTML, CSS and JavaScript). No build step or dependencies.

## Structure
```
index.html          Single-page app markup (all pages/case studies)
css/styles.css      All styles
js/main.js          Page routing, mobile menu, scroll animations
assets/images/      Prototype screens for Mystic India Guide and Antra
vercel.json         Vercel config (clean URLs, caching)
```

## Run locally
Open `index.html` in a browser, or serve the folder:
```
npx serve .
```

## Deploy to Vercel
1. Push this folder to a GitHub repo and import it in Vercel, or run `npx vercel` in this folder.
2. Framework Preset: **Other**. Leave Build Command and Output Directory empty.
3. Deploy.

Fonts (Cormorant Garamond, DM Sans) load from Google Fonts, so an internet connection is needed for the intended typography.
