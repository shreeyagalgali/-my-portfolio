Case Study — 01

Mystic India Guide

A travel discovery platform designed to help users explore authentic and lesser-known destinations in India through a clear and structured experience.

Starting Point

The Idea

The idea started from noticing how difficult it is to find authentic travel experiences, as most platforms focus only on popular tourist destinations.

Problem

Problem Statement

Users struggle to discover meaningful travel experiences because information is scattered, overwhelming, and focused on mainstream locations.

Approach

Problem Solving

I focused on simplifying the discovery process by organizing information into clear categories — nature, culture, heritage, and local experiences.

User Flow

Journey

Explore → Select Category → Browse Regions → View Places → Choose Destination
Implementation

Design

A structured interface with clear navigation, category-based exploration, and detailed destination pages that guide users step by step.

Design Decisions

Key Choices

  • Visual-first homepage for exploration
  • Category-based navigation instead of search-first
  • Step-by-step flow: Category → State → Place
  • Card-based layout for quick scanning
  • Key information shown upfront (ratings, best season)
  • Strong visual hierarchy in detail pages
  • Guided decision-making sections
  • "Help Me Choose" feature for indecisive users
Outcome

Results

The design improves clarity and reduces information overload, making it easier for users to explore and choose destinations with confidence.

Case Study — 02

Antra

A spiritual and self-reflection app designed to help users connect inward through simple, guided, and mindful interactions.

Starting Point

The Idea

Many users feel overwhelmed but lack simple tools for daily reflection and inner connection.

Problem

Problem Statement

Spiritual apps are often too complex or overwhelming for beginners, creating barriers rather than pathways to mindfulness.

Approach

Problem Solving

I focused on simplicity by creating a calm interface with guided interactions and minimal cognitive load — making reflection feel approachable, not intimidating.

User Flow

Journey

Sign Up → Select Interests → Dashboard → Reflection → Content → Discussion → Seek
Implementation

Design

A minimal structure with clear sections for reflection, content, discussions, and search — all within a calm, visually quiet environment.

Design Decisions

Key Choices

  • Minimal and calm UI to reduce mental load
  • Guided onboarding through interest selection
  • Reflection-first homepage
  • Structured content instead of overwhelming feeds
  • Search by feeling, topic, or problem
  • Dedicated discussion space for community
  • Simple bottom navigation
  • Balance between reflection and content
Outcome

Results

The app creates a simple and approachable experience that encourages consistent engagement, making daily reflection feel natural and sustainable.
